
# Cryptopals Challenges

 My solutions to the [Cryptopals Crypto Challenges](<https://cryptopals.com/>) implemented in Python 3 (unfinished yet).

 The goal of this repository is to document my progress while learning about cryptography, Python, and common cryptographic vulnerabilities.

 ## Disclaimer

 **This code is for educational purposes only.**

 Do **not** use this code in production, for real-world cryptographic applications, or to protect sensitive data. The implementations may be incomplete, intentionally insecure, inefficient, or otherwise unsuitable for practical use.

 The code is published as part of my learning process and to demonstrate solutions to the Cryptopals challenges. It should not be considered a reference implementation of any cryptographic algorithm.

 If you need cryptography for a real application, use a well-established and professionally reviewed cryptographic library rather than implementing cryptographic primitives yourself.

 ## Structure

 The repository is organized according to the Cryptopals challenge sets:

```
set1/
set2/
set3/
...
```

Each challenge contains my Python implementation and, where appropriate, supporting code or tests.
